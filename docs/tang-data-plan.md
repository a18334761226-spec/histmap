# 二十四史题材 · 数据源调查与建设方案

> 本文记录 2026-09 的实测调查结论。**核心事实：藩镇粒度的唐代地图，
> 不存在任何许可证干净的现成数据集，必须自己造。** 但底座与史料都已就位。

## 1. 调查结论（按重要性排序）

### ① CHGIS 不能用 —— 这是最大的坏消息

[CHGIS V6](https://chgis.fas.harvard.edu/data/chgis/v6/)（哈佛 + 复旦）是唯一严谨的
中国历史行政区划 GIS 数据集，官方页面写明：

> **License: free for academic research, no commercial use, resale, or
> redistribution permitted.**

而且**时间切片只有 1820 / 1911 / 1990**（清代与现代），**没有唐代面数据**——
唐代只有「时间序列点位」。

- ✅ 能提供：州县治所坐标
- ❌ 没有唐代**面**数据
- ❌ **禁止商用、禁止再分发** → 直接堵死「开源 + 短视频商用」的路

**结论：CHGIS 只能用于开发期交叉验证，绝不能进产物。**

### ② geoBoundaries 是干净的几何底座 ✅

`geoBoundaries` CHN ADM2（实测下载 6.69 MB / 2.1 秒，走代理）：

| 项 | 值 |
|---|---|
| 许可 | **Open Data Commons PDDL v1.0 ≈ 公有领域** |
| 单元数 | **2391 个县级多边形** |
| 顶点数 | 145,801（简化版） |
| 属性 | 仅 `shapeName`（**拼音**，如 `Mohexian`=漠河县）、`shapeID` |

**可商用、可再分发**。2391 个县 → 合并成唐州 → 合并成藩镇，
得到的边界是**真实县界**（不是 Voronoi 直线），且自动沿海岸线切断。

### ③ 史料原文完好，州名截断是解析 bug ✅

`data/processed/fangzhen_raw.json` 存的是《新唐书·方镇表》卷 64–69 的**完整原文**
（6 卷 / 8316 个单元格，其中 265 个含「領」、408 个含「州」）。

原文格式（三种句式都要处理）：

```
置朔方軍節度使，領單于大都護府，夏、鹽、綏、銀、豐、勝六州，定遠、豐安二軍……
置京畿節度使，領京兆、同、岐、金、商五州。是年，以金、商、岐州隸興平鳳翔，同州隸河中。
置邠寧節度使，領州九：邠、寧、慶、涇、原、鄜、坊、丹、延。
置渭北鄜坊節度使，治坊州，並領丹、延二州。
```

解析要点：
- 数量词位置不固定（`六州` / `州九` / `五州`）
- **州名多为单字**（`夏、鹽、綏…`），因为「州」只在末尾出现一次
- 但**府/道名是多字**（`京兆` 是府不是州）→ 早期解析器把 `京兆` 截成了 `兆`
- 要处理**转移关系**（`以金、商、岐州隸興平鳳翔`）
- 要排除非州实体（`都護府` / `二軍` / `三受降城`）

### ④ 唯一还缺的东西：237 个唐州治所坐标

807 年实测：**37 藩镇 / 237 个州**。要把 2391 个现代县归属到州，
最稳的判据是**州治所坐标**（比名字匹配可靠——数据集只有拼音名，古今名也多不同）。

候选来源（都需评估）：

| 来源 | 许可 | 说明 |
|---|---|---|
| GeoNames | CC BY 4.0 | 中国地名库，含坐标；但需处理古今名差异 |
| Wikidata | CC0 | 唐代州治条目，质量参差 |
| CBDB | 待查 | 哈佛中国人物传记库，含历史地名 |
| 《中国历史地名大辞典》 | ❌ 版权 | 不能用 |

## 2. 建设方案

```
《新唐书·方镇表》原文（已有 ✅）
      │  P1 重新解析：州名完整化 + 转移关系
      ▼
藩镇 ← [州] 的逐年隶属（时间序列）
      │
      │  P2 建唐州治所坐标表（237 个）        ← 唯一待解决的数据缺口
      ▼
      │  P3 2391 个现代县 → 最近州治 → 归属    （geoBoundaries PDDL ✅）
      ▼
藩镇面（= 所属州的县的并集，边界为真实县界）
      │  P4 接入统一契约 Region/Frame/Series
      ▼
渲染 / 出片（复用现有引擎与样式层）
```

### 为什么用「县 → 州」而不是「Voronoi 直接生成州」

| | Voronoi from 治所 | 县归属法 |
|---|---|---|
| 边界形状 | 直线，明显合成感 | **真实县界，自然** |
| 海岸线 | 需额外裁剪 | **自动符合** |
| 许可 | 取决于坐标源 | **PDDL 干净** |
| 粒度 | 不可控 | 2391 个县 → 可控 |

### 里程碑

- **T1** 解析器重写 → 产出 `tang_fanzhen_timeline.json`（藩镇×年份×州列表）
  *验收：807 年的州数与《新唐书》记载对得上，且无截断名*
- **T2** 州治所坐标表 → `tang_zhou_gazetteer.json`（237 条，带置信度标注）
  *验收：地图上每个州治点位落在中国境内且位置合理*
- **T3** 县→州归属 + 州→藩镇合并 → `tang_fanzhen_807.geojson`
  *验收：用几何质量闸门跑一遍；藩镇面积与史料描述的量级相符*
- **T4** 接入引擎出一张「唐宪宗二年军阀格局图」
  *验收：保真度与几何闸门双通过，深浅两个主题都能出图*
