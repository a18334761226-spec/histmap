# 风格化层 · 选型与接口契约

> 解决的问题：纯代码渲染出的地图是**数据可视化，不是作品**——色块平、没质感。
> 但让模型逐帧画地图又会漂移、错字、不可复现。这份文档记录我们怎么取舍的。

## 0. 实测结论（2026-09，最贵的那个坑）

**让图像模型「美化」一张地图，它会连同数据一起美化掉。**

用 `Qwen/Qwen-Image-Edit-2509`（硅基流动）对 1942-11 底图做图生图，30 步：

| 指标 | 结果 | 判定 |
|---|---|---|
| 尺寸 | 1920×1080 → **1360×768** | 模型擅自重采样 |
| 结构相似度 NCC | **−0.0745** | 几乎零相关，等于重画了一张 |
| 色块保真 | **33.57%** | 分区颜色基本被抹掉 |

模型确实做出了**非常漂亮的**羊皮纸 + 雕版刻线质感——但它同时：
- 把德国红、苏联紫、英国蓝**全部抹成一片褐色**，地图再也读不出战局
- 把所有中文标注变成**乱码笔画**
- 图例、大事记、口径声明全部作废
- **重画了地理**（凭空多出岛屿）

**根因**：模型不知道哪些像素是「信息」、哪些是「材质」。
你让它美化，它就把两者一起处理，而信息比材质脆弱得多。

### 正确分工与实测对比

同一张底图，两种做法，同一把保真度闸门：

| | 代码质感 `src/postfx.py` | 模型 `Qwen-Image-Edit` |
|---|---|---|
| 尺寸 | 1920×1080 **保持** | 1360×768 被改 |
| NCC | **0.9548** | −0.0745 |
| 色块保真 | **98.95%** | 33.57% |
| 闸门 | ✅ 通过 | ❌ 未通过 |
| 成本 | 0，本地约 1s | 37s + 计费 |
| 帧间一致性 | 确定性，完全一致 | 每帧漂移 |

**结论：材质层归代码，模型只在「无信息」的画面上使用。**
代码版见 `src/postfx.py`：fBm 纸纹 + **乘性调色**（不是加性混色——这是与模型做法的
分水岭，乘性保住了颜色之间的相对差异）+ 暗角 + 做旧边 + 颗粒，并且对高亮度像素
（文字与其描边）**减弱纹理**，因为文字是信息，不该被材质啃掉。

### 模型还能用在哪（安全用法）

1. **生成纯纸纹**：让它输出一张「空白做旧羊皮纸，无文字无图案」，再在代码里当纹理
   叠加。1 次调用，**零内容风险**。
2. **不适用于**：任何含边界、色块、文字的图面。

### 已知未完成

- `postfx` 的 `ink`（宣纸水墨）预设**在深色底图上无效**——宣纸是浅底，
  需要渲染器先出一版浅色主题底图（背景改米白、标注改深墨色）才成立。
  当前不要用它出片。

## 1. 架构决定：模型只跑 1~7 次，不逐帧

```
底图（代码画：国界 / 控制区 / 中文标注 100% 正确）
    │
    ├── 模型跑 1 次（或每个几何年份 1 次，共 7 次）──> 风格样张
    │                                                    │
    │                          拆成两样东西 ◄────────────┘
    │                    ┌───────────────┴───────────────┐
    │              调色映射（LUT）                  纹理层
    │              底图色块 → 风格化后颜色      （样张 − 调色后的底图）
    │                    └───────────────┬───────────────┘
    └──────────── 纯代码套用 ◄───────────┘
                     │
                131 帧全部成片
```

**为什么必须这样**：

| 逐帧调模型 | 本方案 |
|---|---|
| 131+ 次调用（还要算保真度闸门打回重跑） | **1~7 次** |
| 每帧独立生成 → 国界/配色/字体漂移，视频里地图会「呼吸」 | LUT 是确定性的，**帧间完全一致** |
| 同 prompt 两次结果不同，不可复现 | 可复现，可 diff |
| 客户说「德国改深点」→ 得重跑并重新对齐 | 改 LUT 里一个值即可 |
| 换风格 = 重跑全片 | 换风格 = 重跑 1 张样张 |

我们地图是**纯色块**，所以「底图色 → 成图色」的映射是**精确**的而非近似——
这正是代码与模型各自发挥长处的交界。

## 2. 模型选型：Qwen-Image-Edit

针对我们的刚需（**图生图** + **中文标注一个字都不能错**），免费方案里能力最强的是
Qwen-Image 系列。官方仓库原文：

> a 20B MMDiT image foundation model that achieves significant advances in
> **complex text rendering** and **precise image editing** ... exceptional
> performance in text rendering, **especially for Chinese**

`Qwen-Image-2512` 在 AI Arena 一万轮盲测中被评为**最强开源图像模型**。
2026-02 已发布 `Qwen-Image-2.0`，主打专业排版渲染。

**许可证 Apache 2.0 —— 这是决定性因素。**

**无法开源、无法自部署**。而本项目目标是开源 + 上云，所以只有 Apache 2.0
的模型满足要求。附带好处：魔搭的 DiffSynth 支持 4 GB 显存推理，
将来可以完全离线自部署，零 API 成本。

## 3. 接口契约（2026-09 核实，两家完全不同）

### 魔搭 ModelScope —— **异步**

来源：官方 `modelscope/ms-agent` 的 `ms_image_gen.py`

```
POST https://api-inference.modelscope.cn/v1/images/generations
  Authorization: Bearer <SDK Token>
  X-ModelScope-Async-Mode: true          ← 关键，否则行为不一致
  {"model": "...", "prompt": "...", "negative_prompt": "", "image": "data:image/png;base64,..."}
  → {"task_id": "..."}

GET https://api-inference.modelscope.cn/v1/tasks/{task_id}
  Authorization: Bearer <SDK Token>
  X-ModelScope-Task-Type: image_generation   ← 关键
  → {"task_status": "SUCCEED"|"FAILED"|"PENDING"|"RUNNING", "output_images": ["https://..."]}
```

轮询策略照抄官方：2s 起，×1.5 退避到 10s，上限 600s。

### 硅基流动 SiliconFlow —— **同步**

来源：`docs.siliconflow.cn/docs/api/images-generations-post`

```
POST https://api.siliconflow.cn/v1/images/generations
  Authorization: Bearer <API Key>
  X-Enable-Watermark: 0                  ← 仅当下游还要处理时用
  {"model": "...", "prompt": "...", "image": "data:image/png;base64,...", "num_inference_steps": 30}
  → {"images": [{"url": "..."}], "seed": ...}
```

**两家共同点（对我们有利）**：Qwen-Image-Edit **不支持尺寸参数**，
保持输入图原始尺寸 —— 1920×1080 底图进去还是 1920×1080，不会被重采样破坏。

### 水印义务

关闭平台显式水印后，平台条款要求**开发者自行给最终输出加「AI 生成」标识**。
`src/stylize.py` 的 `add_ai_watermark()` 已自动补上，不要去掉。

## 4. 保真度闸门（这是最关键的一环）

模型最常见的失败**不是不好看，而是偷偷重画了文字或边界**——
人眼扫一遍看不出来，但历史区观众会，而且错一个字就是硬伤。

`check_fidelity()` 用两个客观指标卡住：

| 指标 | 阈值 | 抓什么 |
|---|---|---|
| 尺寸一致 | 必须相同 | 模型重采样导致底图细节丢失 |
| 结构相似度 NCC | ≥ 0.90 | 降采样灰度后的归一化互相关，掉了说明图面内容被改 |
| 色块保真 | ≥ 80% | 底图为饱和色块的网格采样点，颜色是否还在同一色系 |

**闸门自检结果**（证明它不是摆设）：
- 同一张图对比自己 → NCC 1.000，通过 ✅
- 拿 1939 的图冒充 1941 的 → NCC 0.841 < 0.90，**正确判失败** ✅

## 5. 已知风险

- 中文文字是模型最容易搞坏的地方，**必须逐张目视复核**，不能只看闸门数值。
- 闸门阈值（0.90 / 80%）是在唯一一对样本上标定的，跑了真实风格化后要重新校准。
- 调色映射 LUT 目前还没实现（等第一张样张出来才能标定映射表）。
